> 本文根据 NEXON 官方 [发行商变更公告](https://cmn-jp.nexon.com/transfer/bluearchive)（2026-10-25 发布，2026-11-12 更新）整理。具体安排、补偿内容与时间以官方公告为准。

2027 年 1 月起，日服《蔚蓝档案》（ブルーアーカイブ）的发行商将由株式会社 Yostar 变更为株式会社 NEXON。游戏的开发公司仍为 NEXON Games，剧情制作与翻译体制不变。

要继续使用当前的游戏账号，必须在预计于 2027 年 1 月中旬实施的发行商变更维护开始前，完成「账号迁移申请」。

> [!WARNING]
> 未与 Yostar ID 绑定的游客账号无法迁移。请先在游戏内完成 Yostar ID 绑定，再于维护开始前提交迁移申请。维护结束后，Yostar ID 将不能再用于登录《蔚蓝档案》。

## 维护前必须完成的两件事

1. **在游戏内将账号与 Yostar ID 绑定。** 游客账号无法直接迁移。
2. **提交账号迁移申请。** 申请页面：[https://ba-account-migration.yostar.co.jp/](https://ba-account-migration.yostar.co.jp/)

申请时请在推荐浏览器中直接打开页面：

- iOS / iPadOS：Safari 最新版
- Android：Google Chrome 最新版
- Windows / macOS：Google Chrome、Microsoft Edge 或 Firefox 最新版
- 不建议从 X 等应用内浏览器直接进入。如遇报错，请选择「在浏览器中打开」，或复制链接后到推荐浏览器重试。
- 建议在 Wi-Fi 等稳定网络环境下办理。

## 哪些内容会继承

- 游戏账号数据会完整继承，包括有偿与无偿的青辉石、已购买的礼包和道具。
- 期限道具的剩余期限在变更后继续有效。
- 游戏内的问候、自我介绍、聊天等内容会继承。
- 在 Yostar ID 中登记的个人信息不会继承。

## 常见问题

### 游客账号可以迁移吗？

不可以。必须先与 Yostar ID 绑定，并在维护开始前完成迁移申请，否则维护后将无法用同一游戏账号登录。

### 变更后还能用 Yostar ID 登录吗？

不能。Yostar ID 将在 2027 年 1 月的发行商变更维护结束后停止用于《蔚蓝档案》，之后需要使用 NEXON 会员账号登录。

### NEXON 会员账号如何注册？

可在 [NEXON 日本免费会员注册页](https://jp.nexon.com/regist/?gm=portal) 注册。已有 NEXON 会员账号的玩家无需重复注册；如果此前是用 X 账号注册的 NEXON 会员，则需要重新注册。免费注册不需要电话号码。NEXON 点数不能在《蔚蓝档案》中使用。

### 有多个 Yostar ID 或多个游戏账号怎么办？

每个游戏账号都可以分别迁移。但 1 个 NEXON 会员账号只能绑定 1 个《蔚蓝档案》游戏账号。

### PC 版和「Yostar games 充值中心」还能用吗？

现有的「ブルーアーカイブPC版」与「Yostar gamesチャージセンター」可使用至发行商变更维护开始前。官方正在准备变更后的新 PC 游玩环境和网页充值服务，具体时间待公布。

### 序列号、期限道具、月卡周卡怎么处理？

- 变更前发行的序列号请在维护开始前使用。
- 期限道具的期限在变更后维持不变。
- 如果维护超过 24 小时、导致无法领取每日奖励，官方表示正在研究延长有效期或补偿等措施。

### 个人资料和游戏内内容会怎样？

在 Yostar ID 中登记的个人信息不会继承；游戏内的问候、自我介绍、聊天等输入内容会继承。

## 还需要注意

- 发行商变更后，将适用 NEXON 的使用条款与隐私政策，首次登录时需要确认并同意。
- NEXON 会员的「支持信息」（姓名、出生日期、电话号码）登记不是迁移的必要条件；完成 SMS 认证后，可以使用网页商店等购买游戏内道具的服务。
- 以 My Number 卡进行的本人确认同样不是迁移的必要条件，但完成后账号丢失时的恢复会更顺利。
- 官方公告未提及第三方客户端。本站将在确认相关情况后另行说明。
