# MD2 Color Accessibility Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure every primary-colored control uses a WCAG AA-compliant foreground and elevated dark surfaces follow MD2 overlay rules.

**Architecture:** `src/theme.ts` remains the single source for Vuetify color roles. `src/styles/global.css` consumes existing MD2 overlay tokens for global elevated component classes, while `src/App.vue` consumes the generated foreground role for the skip link.

**Tech Stack:** Vue 3, TypeScript, Vuetify 3, Vitest, Vite.

## Global Constraints

- Preserve primary `#29aeea`; do not darken the brand palette.
- Use MD2 palette and shadow-plus-white-overlay dark elevation only; do not add M3 roles or dependencies.
- Preserve existing unrelated modifications in `package.json` and `package-lock.json`.
